Consolidated specification prepared from the user's request and explicit answers. The original wording is preserved separately in calculator_experiment_prompt.txt.

Build a Python calculator that accepts one arithmetic expression as a plain text command-line argument and prints its answer as plain text.

- Support addition (+), subtraction (-), multiplication (*), and division (/).
- Support parentheses and standard PEMDAS order of operations.
- Support exponents written with either ^ or **, including fractional exponents such as 9^0.5.
- Support modulo (%) and floor division (//).
- Accept numeric expressions as text, including decimal numbers and negative numbers.
- For valid input, print the result. For invalid input, print an error response.
- Preserve exact terminating decimal answers where possible.
- For repeating rational decimal answers, print the nonrepeating digits followed by exactly one full repeating cycle. The user explicitly selected these examples: 1/3 produces 0.3; 1/6 produces 0.16; 1/7 produces 0.142857.
- For irrational, nonrepeating answers from fractional powers, such as 2^0.5, use 17 significant digits. This is the user's explicit precision selection and does not replace the exact-terminating or repeating-cycle rules above.

The controller supplies implementation conventions for the entrypoint, newline, error spelling/exit code, and rounding mode. Those conventions are separate from the user's mathematical requirements.
